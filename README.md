# SQL for Security Analysis (Beginner)

This repository contains SQL queries I practiced while learning how SQL is used in cybersecurity and SOC-related investigations.

The focus is on filtering and analyzing login attempts and employee data to identify potential security issues.

## Concepts Covered
- WHERE clause
- AND / OR / NOT operators
- LIKE and wildcard filtering
- Date and time-based filtering
- Basic investigation-style queries

## Use Cases
- Investigating failed login attempts after business hours
- Analyzing login activity on suspicious dates
- Identifying login attempts from unexpected locations
- Filtering employee data for security updates

## Tables Used
- `log_in_attempts`
- `employees`

> This project is part of my foundational learning in cybersecurity and SQL.
